team16-중국계 직구 플랫폼에 대한 국내 언론의 여론 분석 프로젝트

[팀원]
무역학부 202641120 김서영
무역학부 202641131 김태훈

[프로젝트 소개]
구글 뉴스 RSS를 활용해 알리익스프레스와 테무 등 해외 직구 플랫폼에 대한 국내 언론의 보도 자료를 수집하고 분석하는 프로젝트다. 수집된 기사 데이터를 바탕으로 시계열 발행량 추이, 키워드 감성 분석 및 워드클라우드 시각화를 수행하여 해외 직구 플랫폼들에 대한 국내 여론의 흐름을 한눈에 파악할 수 있도록 돕는다.

[실행방법]
프로젝트를 실행하기 위해 파이썬 터미널에서 다음 절차를 따른다.
1.라이브러리 설치
-파이썬 터미널을 열고 필요한 외부 라이브러리(streamlit,pandas,feedparser,matplotlib,wordcloud)들을 설치한다.
2.프로그램 구동
터미널에 'streamlit run team16.py'라고 입력 후 웹브라우저 실행을 기다린다.
3.데이터 분석 수행
브라우저 화면이 뜨면 상단의 검색 키워드 입력창에 분석하고 싶은 단어(예: 알리익스프레스 OR 테무)를 입력한 후 아래에 있는 '크롤링 시작' 버튼을 누른다. 버튼을 누르면 구글 뉴스 데이터 수집 및 감성 분석, 시각화가 진행된다. 분석 완료 후 뉴스 목록, 날짜별 기사 발행량 변화 그래프, 감성 비중 그래프, 워드클라우드가 출력된다. 결과 데이터는 crawled_data.csv 파일로 해당 폴더에 자동 저장된다.

[사용라이브러리]
-streamlit
-pandas
-requests
-beautifulsoup4
-matplotlib
-wordcloud
