다음의 기능을 가지는 해외 직구 플랫폼에 대한 국내 언론의 여론 변화 분석 프로그램을 파이썬으로 작성해줘


[인터페이스 설명]
- 사용자 인터페이스는 streamlit을 사용한다
-URL 입력창은 구글 뉴스 RSS 검색 베이스 URL(https://news.google.com/rss/search?q=)을 기본값으로 받는다
-"크롤링 시작" 버튼을 위치시킨다
-크롤링 결과(기사 목록)는 데이터프레임 형태로 출력한다
-시각화 결과(그래프 및 워드클라우드)는 streamlit 화면에 직접 출력한다

[기능]
1."크롤링 시작" 버튼: 버튼 클릭 시 데이터 수집 및 분석 프로세스를 시작한다
2.데이터 수집 : 구글 뉴스 RSS 피드를 활용하여 설정된 키워드에 대한 XML 데이터를 수집한다. BeautifulSoup의 xml 파서 또는 feedparser를 활용한다.
3.데이터 저장: 크롤링한 데이터를 'crawled_data.csv' 파일로 저장한다(utf-8-sig 인코딩 적용)
4.여론 분석 및 시각화
-시계열 선 그래프: RSS의 pubdate 정보를 활용하여 날짜별 기사 발행량 변화를 분석
-감성 분석 막대 그래프: 기사 제목의 키워드를 기반으로 긍정/부정/중립 여론 비중 분석
-워드클라우드: 수집된 보도 자료 내 주요 키워드 시각화

[데이터 설명]
-구글 뉴스 RSS의 <item> 태그 내 데이터를 활용한다.
-데이터 컬럼은 '날짜', '제목', '언론사', '플랫폼(알리/테무)', '감성점수'로 구성한다.
-구글 뉴스 제목 특성상 제목 - 언론사 형태로 들어오므로 이를 분리하여 저장한다.

[코드 작성 요구사항]
-에러 처리 포함(연결 실패,데이터 부재, 라이브러리 미설치 등)
-메인 실행 부분은 main() 함수로 정의
-간결하게 작성 (불필요한 코드 제외)
-기능별(크롤링, 전처리, 감성분석, 시각화)로 함수를 만들어서 구현
-이모티콘을 절대 사용하지 말 것
-각 함수와 주요 코드에 주석 포함
-Matplotlib 사용 시 한글 깨짐 방지를 위한 폰트 설정 코드를 포함
